# Marco-Juridico-IA-Mexico
Guía interactiva sobre Inteligencia Artificial y el marco jurídico mexicano. Proyecto educativo enfocado en privacidad, ética, propiedad intelectual y derechos digitales.



AI-Legal-MX es una herramienta educativa desarrollada para facilitar la consulta de temas relacionados con la Inteligencia Artificial y su interacción con el marco jurídico mexicano.

El proyecto proporciona información básica sobre regulación, protección de datos personales, derechos digitales, ética en IA y propiedad intelectual mediante una interfaz de consola sencilla desarrollada en Python.

## Objetivos:
* Difundir conceptos jurídicos relacionados con la Inteligencia Artificial.
* Facilitar el acceso a información normativa relevante en México.
* Promover la alfabetización digital y jurídica en temas emergentes de IA.
* Servir como proyecto introductorio para estudiantes y profesionales del Derecho interesados en la Inteligencia Artificial.

## Tecnologías utilizadas
* Python 3
* Git
* GitHub

## Temas incluidos:
* Protección de Datos Personales
* Derechos Humanos e Inteligencia Artificial
* Propiedad Intelectual e IA
* Ciberseguridad
* Ética y Gobernanza de IA
